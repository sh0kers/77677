# HolyWorld TNT Builder 1.5.0 (Fabric 1.21.4)

Клиентский мод. Одна кнопка (по умолчанию **G**, меняется в Управление -> HolyWorld):

1. ставит **Тнт-Пушку** туда, куда смотрит прицел, и сразу открывает её;
2. кладёт **Динамит B** (по умолчанию 1 штуку) и закрывает окно;
3. ставит рядом **редстоун блок** - пушка стреляет один раз;
4. ломает раздатчик киркой.

Все шаги, которым не нужно ждать сервер, выполняются в одном тике. Ломание раздатчика начинается
заранее и рассчитано так, чтобы блок сломался не раньше чем через 5 тиков после редстоуна
(раздатчик стреляет через 4 тика).

Перед стартом мод проверяет, что в инвентаре есть пушка, динамит B, редстоун блок и кирка.
Повторное нажатие G во время работы - остановка. Ошибки пишутся в чат.

## Использование
- Прицел на блок (куда ставить), **без Shift**, нажать G.
- Удали старые jar мода из mods. Нужны Fabric Loader 0.16.9+, Fabric API, Java 21.

## Настройки (`.minecraft/config/holyworld-tntbuilder.json`)
- `tntPerCannon` - сколько динамита класть в пушку (1);
- `fireDelayTicks` - минимум тиков между редстоуном и поломкой пушки (5; меньше 5 нельзя). Если пушка не стреляет - увеличь;
- `clickDelayTicks` - пауза между кликами по слотам (0 = всё в один тик). Если сервер кикает за скорость - поставь 1-2;
- `breakRedstoneBlock` - ломать ли и редстоун блок (false);
- `cannonName`, `tntName` - части названий предметов;
- `breakTimeoutTicks` - таймаут ломания.

## Сборка
GitHub Actions: загрузи все файлы (включая `.github/workflows/build.yml`), вкладка Actions -> build -> скачай артефакт, jar без `-sources`.
Локально: JDK 21 + Gradle 8.12, `gradle build`, jar в `build/libs/`.
